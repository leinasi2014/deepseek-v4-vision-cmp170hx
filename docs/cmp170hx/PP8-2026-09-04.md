# DSV4-Vision PP8 测试记录（2026-09-04）

硬件：8× CMP 170HX，PP8 × TP1，DSV4-Vision-Exp 权重，DSpark n=5。
测试口径：~2k token prompt × 1024 token 生成 × N 路并发，聚合吞吐（t/s）。

## 结果

| 配置 | 单流 | 64 并发 | 128 并发 | 显存峰值 |
|---|---|---|---|---|
| bat8192 / seqs128 / util0.85 | 75 | **673** | 660 | 58.9 GiB |
| bat2048 / seqs128 / util0.88 / graph768 | — | 507 | **819** | 61.2 GiB ⚠ |
| bat8192 / seqs128 / util0.85 / graph768 | — | 见附注 | 见附注 | — |

- 全程 Xid = 0
- DSpark 开/关（64 并发）：514 vs 478，高并发持平；单流保留（75 vs ~55）
- graph768（`--compilation-config '{"max_cudagraph_capture_size":768}'`）：128 并发 +24%
- util0.88 显存 61.2 GiB 贴近 62 GiB 红线，生产建议 util0.85

## Prefill（真实环境口径，生产容器实测）

| 场景 | 命中 | 耗时 | 吞吐 |
|---|---|---|---|
| 冷·30k 新 prompt | 0% | 5.45s | **5,508 t/s** |
| 冷·60k 新 prompt | 0% | 9.35s | **6,420 t/s** |
| 热·30k 重发 | 99% | 0.58s | 52,109 t/s（等效） |
| 热·agent 轮次（30k 基底+500/轮） | 97% | 0.66-0.72s/轮 | 42-46k t/s（等效） |

注：另有一次冷 30k 出现 40s 异常（疑首 JIT/池扩容瞬态，复测未见）；生产 agent 多轮流量走热路径，每轮 <1 秒。
